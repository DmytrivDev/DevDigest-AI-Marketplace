Guide

How to add this marketplace to Claude Code, install plugins and use what's inside.

Add the marketplace

Run this once in Claude Code. It registers the repository as a marketplace named devdigest-marketplace.

Install a plugin

Install by plugin name and marketplace. Everything inside the plugin is installed together: skills, agents, commands, hooks and the MCP server.

If the new commands don't show up, restart Claude Code.

Find and invoke

Search the catalog in plain words, then copy the command from the card. Skills and commands are invoked by name:

Agents, hooks and MCP servers have no command of their own. Claude delegates to agents when a task matches, hooks run on their event, and MCP servers start with the plugin.
