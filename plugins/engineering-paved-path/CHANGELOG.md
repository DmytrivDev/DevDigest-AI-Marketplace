# Changelog

All notable changes to `engineering-paved-path` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
plugin follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-10-16

### Added

- `react-best-practices`: a catalog of modern React practices and anti-patterns.
- `next-best-practices`: Next.js App Router conventions, RSC boundaries, data patterns and optimization rules.
- `fastify-best-practices`: Fastify routes, plugins, schemas, hooks, errors, security, testing and deployment.
- `react-testing-library`: React Testing Library with Vitest, using user-flow tests and MSW mocking.
- `security`: web application security checklists and examples based on the OWASP Top 10:2025.
- `onion-architecture`: Onion Architecture rings, ports and adapters, and layering rules for Node/TypeScript backends and MCP servers.
- `frontend-ui-architecture`: component homes, file roles, logic and state placement, and the Next.js server/client boundary.
