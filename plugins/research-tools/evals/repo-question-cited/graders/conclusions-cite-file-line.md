Every numbered item under `Conclusions` has at least one evidence line that cites a file path
with a line number or line range, in the form `path/to/file.ts:12` or `path/to/file.ts:12-19`
(for example `src/payments/client.ts:12`). No conclusion rests only on a file name without a
line, on a search result, or on an uncited statement.
